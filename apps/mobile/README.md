# Mobile foundation

This app is now a real Android-targeted shell scaffold inside the VK-focused workspace.

Current structure:

- `app/` contains the mobile Next.js entry and the adapted connect screen
- `src-tauri/` contains the dedicated Tauri mobile shell for Android packaging
- `src-tauri/gen/android/` is generated by `npm run mobile:tauri:android:init`

What is already shared with desktop:

- `@whitelist/contracts`
- shared `i18n` provider in `packages/ui/src/OdinI18n.tsx`
- shared app shell in `packages/ui/src/AppShell.tsx`
- shared connect hero in `packages/ui/src/ConnectScreenHero.tsx`

What is intentionally not finished yet:

- native Android `VpnService` bridge
- tunnel lifecycle on device
- secure mobile-side profile persistence
- live network flow validation on Android

Build path:

```bash
npm install
npm run mobile:tauri:android:init
npm run mobile:tauri:android:build
```

Android env notes:

- project Android commands are wrapped by `apps/mobile/scripts/android-env.sh`
- that wrapper pins JDK 21 and the local SDK/NDK under `~/.local/android-sdk`
- `tauri android init` is completed and `src-tauri/gen/android/` now exists
