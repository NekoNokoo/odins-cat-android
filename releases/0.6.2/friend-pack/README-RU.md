# Odin's Cat 0.6.2 Friend Pack

Что внутри:
- `Odins-Cat-0.6.2.apk` — Android APK
- `Odin-One-Yandex-Camo-Bypass-0.6.2.odinone-access.json` — профиль для импорта
- `SHA256SUMS.txt` — SHA-256 хэши файлов

Как проверить:
1. По желанию сравнить SHA-256 из `SHA256SUMS.txt`.
2. Установить `Odins-Cat-0.6.2.apk`.
3. Открыть приложение и импортировать `Odin-One-Yandex-Camo-Bypass-0.6.2.odinone-access.json`.
4. Подключиться через импортированный профиль.

Что делает этот профиль:
- основной путь: двуххоповый HTTPS front + `xhttp`
- первый hop идёт через российскую поверхность
- это повышает шанс пройти белые списки
- часть российских сайтов настроена на direct bypass, чтобы они открывались вне VPN

Если после импорта в приложении уже есть старые профили:
1. Выбрать именно новый импортированный профиль.
2. Если что-то ведёт себя странно, очистить данные приложения и импортировать только этот файл заново.
